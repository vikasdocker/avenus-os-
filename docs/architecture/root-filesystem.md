# Root Filesystem Design

The Phase 1.2 root filesystem is generated by Buildroot and extended by the Aether
overlay in `infra/buildroot/external/overlays/rootfs`.

## Required Directories

| Directory | Purpose |
| --- | --- |
| `/bin` | BusyBox applets and essential commands. |
| `/sbin` | Aether init and shutdown entry points. |
| `/etc` | System configuration and Aether service configuration. |
| `/dev` | Device nodes from devtmpfs. |
| `/proc` | Kernel process and system information. |
| `/sys` | Kernel device and subsystem information. |
| `/run` | Runtime state, health files, and IPC readiness files. |
| `/tmp` | Temporary writable storage with sticky bit. |
| `/var` | Logs and mutable state. |
| `/home` | Developer shell home base. |
| `/usr` | Aether service binaries and BusyBox support scripts. |

## BusyBox Scope

BusyBox provides the initial shell and development commands needed to inspect boot,
network, mounts, processes, logs, and shutdown behavior. Additional userland packages
must be justified by a Phase requirement before inclusion.
