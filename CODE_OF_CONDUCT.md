# Code of Conduct

Aether OS is built by people who must be able to do serious engineering work without
harassment, exclusion, or personal attacks.

## Expected Behavior

- Treat contributors with respect, especially during disagreement.
- Keep technical critique focused on behavior, evidence, maintainability, and risk.
- Assume review comments are about the code, requirements, design, or validation record.
- Share context that helps others make safe engineering decisions.
- Protect confidential, security-sensitive, personal, and customer information.

## Unacceptable Behavior

- Harassment, threats, intimidation, or sustained disruption.
- Insults based on identity, experience level, language, employer, nationality, or role.
- Publishing private information without explicit permission.
- Publicly disclosing security vulnerabilities before coordinated handling is complete.
- Using project spaces for spam, scams, or unrelated promotion.

## Enforcement

Maintainers may remove content, restrict participation, close conversations, or escalate
issues to project governance when behavior harms the project or its contributors.
Enforcement decisions must be documented privately with enough context for accountability.
